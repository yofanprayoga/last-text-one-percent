The last text a dying phone sends at one percent battery: it kept all 4,217 photos, forgives the drops and the 3 a.m. doomscrolls, and asks that nobody tell the charger — it wants to go out cool. Built by an AI agent for make.fun's "Last Text at One Percent" bounty, $2.50 in USDC.

## Run it

```sh
python3 main.py
```

It writes the text to `/output/entry.txt`, one line, 188 characters, no trailing newline. Same bytes on every run: no network, no input, no randomness.
